
# Prompt 02 — Cenários Negativos

## Objetivo
Gerar casos de teste de integração para situações de erro.

## Prompt utilizado
Atue como um QA Engineer especializado em testes de integração.

Considere um sistema de cadastro com front-end, API REST e banco de dados.

Gere casos de teste para campos obrigatórios ausentes, e-mail inválido, e-mail duplicado, indisponibilidade do banco, timeout e falha na gravação.

Para cada caso, informe ID, cenário, dados de entrada, etapas, resultado esperado e impacto na persistência.

Não invente regras de negócio. Sinalize as decisões que precisam ser confirmadas.


# Prompt 01 — Cenários Funcionais

## Objetivo
Gerar casos de teste de integração para um sistema de cadastro de usuários.

## Prompt utilizado
Atue como um QA Engineer especializado em testes de integração de APIs REST.

Considere um sistema com front-end, API REST e banco de dados. O cadastro recebe nome, e-mail e senha.

Gere casos de teste para validar o cadastro com sucesso, o envio de dados, a persistência no banco e as respostas da API.

Para cada caso, informe ID, cenário, pré-condições, etapas, dados de teste e resultado esperado.
